# SalesScope frontend

The React and TypeScript interface implements two required states and one optional state:

1. prepare the report on one page by uploading a file, confirming mappings, and choosing cleanup rules;
2. view the detailed weekly report when the file supports analysis; and
3. optionally verify the report using formulas, source-row counts, spreadsheet instructions, and a downloadable CSV.

See the repository [README](../README.md) for the product problem, setup, data expectations, architecture, and verification workflow.
